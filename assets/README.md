# Assets

Questa cartella dovrebbe contenere le icone e le immagini dell'app.

Per generare le icone necessarie:

1. Crea un'icona di 1024x1024px
2. Usa un servizio come [https://www.appicon.co/](https://www.appicon.co/) per generare tutte le dimensioni
3. Metti i file qui:
   - `icon.png` - Icona principale (1024x1024)
   - `splash.png` - Schermata di caricamento
   - `adaptive-icon.png` - Per Android
   - `favicon.png` - Per web

Per ora, l'app funzionerà anche senza queste icone, Expo userà dei placeholder di default.
